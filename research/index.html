Research

RSI reading list

Huxley-Gödel Machine: Human-Level Coding Agent Development by an Approximation of the Optimal Self-Improving Machine

Wenyi Wang, Piotr Piękos, Li Nanbo, Firas Laakom, Yimeng Chen, Mateusz Ostaszewski, Mingchen Zhuge, Jürgen Schmidhuber

arXiv, 2025

  • arXiv
  • Code

HGM uses benchmark outcomes from an agent’s descendants to estimate how promising its branch is for future self-modifications. The score guides where to expand a tree of coding-agent variants.

Darwin Godel Machine: Open-Ended Evolution of Self-Improving Agents

Jenny Zhang, Shengran Hu, Cong Lu, Robert Lange, Jeff Clune

arXiv, 2025

  • arXiv
  • Project
  • Code

A coding agent proposes edits to its own implementation and evaluates the resulting variants on programming benchmarks. An archive retains diverse candidates for future exploration, including variants that are not the current highest scorers.

Recursive self-improvement of AI research agents (AIDE²)

Dhruv Srikanth, Bingchen Zhao, Dixing Xu, Yuxiang Wu, Zhengyao Jiang

arXiv, 2026

  • arXiv
  • Project

An outer research agent edits the current inner agent. An inner search then produces code for multiple R&D tasks, and private evaluation scores decide which agent version is carried forward.

Self-Taught Optimizer (STOP): Recursively Self-Improving Code Generation

Eric Zelikman, Eliana Lorch, Lester Mackey, Adam Tauman Kalai

COLM, 2024

  • arXiv
  • Code

A language-model-powered improver edits its own optimization program. A meta-utility measures how well the resulting improver improves programs on downstream tasks, producing a sequence of revised improvers.

MCon: Building an Elastic Cloud for Android Applications with Framework Consolidation

Jiaxing Qiu, Zijie Zhou, Zhenhua Li, Hongyi Wang, Zizhang Liu, Yunhao Liu, Yumeng Liang, Jie Wu, Wen Xia, Tianyin Xu

SOSP, 2026

  • Paper
  • Project

Android tenants share one running framework while retaining private views through IPC virtualization and per-tenant virtual device slices. New app environments avoid reinitializing the framework.

SANDHI: Fine-Grained Merging for Memory Efficient Multi-Model Serving

Vima Gupta, Oytun Kuday Duran, Nandan Suresh Meda, Ikhyun An, Ganesh Ananthanarayanan, Anand Iyer

SOSP, 2026

  • Paper
  • Artifact

SANDHI measures which weights in fine-tuned models tolerate perturbation, merges selected components under accuracy constraints, and maps those components to shared GPU memory during multi-model serving.

DeltaBox: Scaling Stateful AI Agents with Millisecond-Level Sandbox Checkpoint/Rollback

Yunpeng Dong, Jingkai He, Shiqi Liu, Yuze Hou, Dong Du, Zhonghu Xu, Si Yu, Baochuan Yang, Yubin Xia, Haibo Chen

arXiv, 2026

  • arXiv
  • PDF

DeltaBox checkpoints both filesystem and process state. Copy-on-write layers capture file changes, while incremental dumps and frozen process templates reduce the cost of branching from an intermediate sandbox state.

Agentix: An Efficient Serving Engine for LLM Agents as General Programs

Michael Luo, Xiaoxiang Shi, Colin Cai, Tianjun Zhang, Justin Wong, Yichuan Wang, Chi Wang, Yanping Huang, Zhifeng Chen, Joseph E. Gonzalez, Ion Stoica

USENIX NSDI, 2026

  • Paper
  • PDF
  • Preprint (Autellix)

Agentix tracks calls as part of a program session and uses their execution history in its scheduler and load balancer. The aim is to reduce end-to-end program latency and improve KV-cache reuse across calls.

MinT: Managed Infrastructure for Training and Serving Millions of LLMs

Mind Lab

arXiv, 2026

  • arXiv
  • SDK
  • Server

MinT keeps expensive base models resident and treats exported LoRA adapter revisions as the units of rollout, training, evaluation, serving, and rollback. Versioned adapters support large policy catalogs with bounded engine-local working sets.

RSIGym: A Flexible Environment for Recursive Self-Improvement

Fanqing Meng, Lingxiao Du, Haocheng Lu, Qiguang Chen, Ziqi Zhao, Zijian Wu, Jiayuan Zhuo, Mengkang Hu, Michael Qizhe Shieh

arXiv, 2026

  • arXiv
  • PDF

RSIGym exposes training, inference, rollout, evaluation, and sandboxes as services so a research agent can carry accepted changes into later rounds. The benchmark studies data changes, harness changes, and joint changes.

Agent Lightning v1.0: Towards Harnessed Agentic RL

Zhiyuan He, Siwei Zhang, Zhiwen Zhou, Yuqing Yang, Yu Kang, Yuge Zhang, Luna K. Qiu, Tin Yan Tsui, Jiahang Xu, Chong Luo

arXiv, 2026

  • arXiv
  • Code
  • Docs

A model API gateway captures interactions from an existing agent harness for reinforcement learning. The report examines how to reconstruct training samples, assign credit, normalize losses, and schedule training with asynchronous rollout.

Crab: A Semantics-Aware Checkpoint/Restore Runtime for Agent Sandboxes

Tianyuan Wu, Chaokun Chang, Lunxi Cao, Wei Gao, Wei Wang

arXiv, 2026

  • arXiv
  • Code

Crab observes the operating-system effects of each agent turn to choose a checkpoint strategy. It overlaps checkpoint work with model wait time and coordinates checkpoint traffic when multiple sandboxes share a host.

Branching Policy Optimization: Sandbox-Native Language Agent Reinforcement Learning

Bowei He, Yankai Chen, Xiaokun Zhang, Xue Liu

WAIC Academic, 2026

  • arXiv
  • PDF

Branching Policy Optimization forks rollouts from saved intermediate sandbox states and compares returns within sibling branches. Its rollout tree shares prefixes and provides a local baseline for the decision at a fork.

AReaL: A Large-Scale Asynchronous Reinforcement Learning System for Language Reasoning

Wei Fu, Jiaxuan Gao, Xujie Shen, Chen Zhu, Zhiyu Mei, Chuyi He, Shusheng Xu, Guo Wei, Jun Mei, Jiashu Wang, Tongkai Yang, Binhang Yuan, Yi Wu

arXiv, 2025

  • arXiv
  • Code

AReaL decouples rollout from policy updates so generation can continue while the trainer works. Bounding policy staleness matters because higher rollout throughput can otherwise feed the trainer samples from policies that have drifted.

GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

Lakshya A. Agrawal, Shangyin Tan, Dilara Soylu, Noah Ziems, Rishi Khare, Krista Opsahl-Ong, Arnav Singhvi, Herumb Shandilya, Michael J. Ryan, Meng Jiang, Christopher Potts, Koushik Sen, Alexandros G. Dimakis, Ion Stoica, Dan Klein, Matei Zaharia, Omar Khattab

ICLR (Oral), 2026

  • arXiv
  • Code

GEPA reflects on execution traces and feedback in natural language to propose prompt changes. Pareto selection preserves candidates that solve complementary examples, giving later prompt revisions several useful starting points.
