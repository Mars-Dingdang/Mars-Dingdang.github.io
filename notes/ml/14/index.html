ML 14: Model Interpretability and Feature Attribution

Derive the weighted fit in LIME and prove completeness for Integrated Gradients and efficiency for Shapley values.

The model is locally flat at the input, but the path from the baseline crosses a segment of slope one.

Local Interpretable Model-Agnostic Explanations

Lecture 14, slides 4–12. Ribeiro, Singh, and Guestrin, Sections 3.1–3.3.

A human-readable explanation should fit the reader’s working memory and state a claim that can be checked. A sufficiently large decision tree can be difficult to inspect. Attribution methods simplify a single prediction to a collection of feature contributions. The feature representation, the score to explain, and the reference used to measure contribution all belong to the problem definition.

For an input \(x\), sample nearby or masked inputs \(z_j\) and compute the black box’s scores \(f(z_j)\). Fit an interpretable model \(g\) on human-readable representations \(z'_j\) via

\[\min_g \sum_j \pi_x(z_j)(f(z_j)-g(z'_j))^2+\Omega(g).\]

In the slide formulation, \(\pi_x(z)=\exp(-D(x,z)^2/\sigma^2)\). It emphasizes nearby inputs according to the selected distance \(D\). A mask \(z'\) might encode present words in a text or visible superpixels in an image. The inverse mapping from the mask to an input determines what the black box actually evaluates. The penalty \(\Omega\) limits complexity, for example the number of nonzero coefficients. On a fixed feature set and without the penalty, write the design as \(A\), weights as a diagonal matrix \(W\), and responses as \(f\). Differentiating \((A\beta-f)^\top W(A\beta-f)\) gives the normal equation \(A^\top WA\beta=A^\top Wf\). Kernel width and the distribution of perturbed examples determine the fitting problem. For a direction \(h\), the derivative of the weighted squared loss is \(2h^\top A^\top W(A\beta-f)\). Its quadratic term in \(h\) is \(\|W^{1/2}Ah\|^2\), so the normal equation suffices for a minimizer, and full column rank of \(W^{1/2}A\) gives uniqueness. A fixed support lets us use this unconstrained calculation on just its active columns. An \(\ell_1\) penalty is a soft surrogate for selecting at most \(k\) nonzeros and changes the optimum; it is not an algebraic conversion of the hard constraint.

A model flat near \(x\) can have near-zero fitted slopes even when its output differs substantially from a meaningful baseline. For example, \(\operatorname{ReLU}(x)\) is zero in a neighborhood of \(x=-5\), while the output changes by one relative to baseline \(x'=1\). The slide’s black-image example sets an explicit comparison point. Two different baselines can yield different allocations because they define different output differences and paths.

Integrated Gradients along a baseline path

Lecture 14, slides 12–16. Sundararajan, Taly, and Yan, Sections 2–4.

Set \(\gamma(t)=x'+t(x-x')\) for baseline \(x'\). The attribution for coordinate \(i\) is

\[\operatorname{IG}_i(x;x')=(x_i-x'_i)\int_0^1\partial_iF(\gamma(t))\,dt.\]

When \(F\circ\gamma\) is absolutely continuous and the chain rule holds almost everywhere along the path, summing the attributions gives

\[\sum_i\operatorname{IG}_i =\int_0^1\nabla F(\gamma(t))^\top (x-x')\,dt =\int_0^1 (F\circ\gamma)'(t)\,dt=F(x)-F(x').\]

This is completeness. If only coordinate \(i\) differs from baseline and the output changes, every other factor \(x_j-x'_j\) is zero, so all nonzero difference is assigned to \(i\) (sensitivity a). If \(F\) is independent of coordinate \(i\), its partial derivative there is zero wherever defined, and the attributed integral is zero (sensitivity b). Implementation invariance follows on paths where the relevant derivatives exist almost everywhere: any two mathematical implementations of the same function have the same partial derivatives at those points. An autodiff choice at a kink along the whole path needs special care. A componentwise finite-difference ratio cannot in general be propagated like a Jacobian: there is no single secant gradient canonically determined by two points in multiple dimensions. Linearity follows by taking partial derivatives and integrals of \(aF_1+bF_2\).

For symmetry, suppose swapping features \(i\) and \(j\) leaves \(F\) unchanged, and the baseline and input each have equal coordinates in the two positions. At every point on the straight path those coordinates agree. Differentiating the equality under the swap gives \(\partial_iF=\partial_jF\) on that path wherever both derivatives exist. The prefactors also agree, so both attributions are equal. For \(F(x)=\min\{\max(x,0),1\}\) from baseline 0 to input 2, the path lies in the unit-slope region for half its duration. The contribution is \(2(1/2)=1\) despite zero endpoint derivative. Numerical quadrature can be checked by the residual in completeness.

Which single path preserves symmetry?

The slide’s example uses \(F(u,v)=uv\) from \((0,0)\) to \((1,1)\). A path moving \(u\) first and then \(v\) attributes all one to \(v\), because the integral for \(u\) runs where \(v=0\). A straight path gives \((1/2,1/2)\). More generally, on the normalized two-coordinate problem, a continuous coordinatewise-monotone, piecewise smooth single path preserves symmetry for every smooth symmetric \(F\) only if it stays on the diagonal, up to reparameterization. This is the symmetry test underlying the paper’s path result.

To see necessity, path attribution to the first coordinate is \(\int_0^1 F_u(u,v(u))\,du\), where \(v(u)\) is the height of the path at horizontal position \(u\) for almost every \(u\). Vertical segments have zero first-coordinate contribution. Its difference from the diagonal attribution is

\[\int_0^1\int_u^{v(u)}F_{uv}(u,s)\,ds\,du.\]

If the path goes above the diagonal, there is an open region with \(u<s<v(u)\), away from vertical endpoints. Its reflection across the diagonal cannot lie in the region between path and diagonal: monotonicity gives \(v(s)\ge v(u)>s\), so the reflected height \(u<s\) is below both. Pick a smooth nonnegative bump within this open region and add its reflected bump. Let this symmetric sum be \(F_{uv}\), integrating once in each variable from zero to obtain a smooth symmetric \(F\). The double integral is strictly positive, while its reflected bump gives no contribution. A path below the diagonal is treated by swapping coordinates. By completeness the two attributions deviate in opposite directions from their equal diagonal shares. For the normalized problem from \(\mathbf0\) to \(\mathbf1\) in \(n\) dimensions, apply the same argument to every pair of coordinates and choose test functions depending only on that pair. If any projected pair leaves the diagonal, its two attributions differ for one such symmetric test function. Thus all coordinate paths agree and the full path is \(\gamma(t)=\lambda(t)\mathbf1\) for a common nondecreasing parameter \(\lambda\). Changing variables in the line integrals gives exactly Integrated Gradients. For inputs with unequal coordinate increments, the same characterization applies to single-path rules that are equivariant under independently translating and scaling the coordinate intervals. Normalize each nonconstant coordinate to \([0,1]\), use the pairwise argument with common endpoints, then undo the normalization. A constant coordinate gives zero under a coordinatewise-monotone path. This states the hypotheses under which the straight path is determined by the symmetry argument. Averaging several paths can also preserve symmetry, as the permutation construction below illustrates.

Shapley values as averages over permutations

Lecture 14, slides 18–21. Lundberg and Lee, Sections 2–4.

Let \(v(S)\) be the prediction-related value for a coalition of available features \(S\) from feature set \(N\). The Shapley attribution is

\[\phi_i=\sum_{S\subseteq N\setminus\{i\}} \frac{|S|!(|N|-|S|-1)!}{|N|!}\,[v(S\cup\{i\})-v(S)].\]

The coefficient is the probability that exactly \(S\) precedes \(i\) in a uniform random permutation: order these predecessors arbitrarily, then order all successors. For any fixed permutation, the marginal contributions telescope to \(v(N)-v(\varnothing)\). Averaging proves efficiency. Symmetric participants exchange positions through a bijection of permutations and hence receive the same average. A dummy with zero marginal contribution receives zero, and linearity follows by taking expectations. For a pure interaction \(v_T(S)=\mathbf1\{T\subseteq S\}\), an element of \(T\) receives the unit contribution exactly when it is last among \(T\). Its attribution is therefore \(1/|T|\). These pure interactions also span all games with \(v(\varnothing)=0\) by subset inclusion–exclusion, which gives uniqueness under these axioms.

SHAP specifies a value function and an approximation or evaluation procedure. Examples include filling missing features with a fixed baseline, integrating over background features, or conditioning the missing features on observed ones. Correlation means these choices answer different questions. In a conditional game, a feature can get credit for information about another feature on which the model directly depends.

Why Shapley weights give the unique additive attribution

Write \(v(\varnothing)=0\) after subtracting the baseline. For nonempty \(T\subseteq[d]\), let \(u_T(S)=\mathbf1\{T\subseteq S\}\). Every set function has a unique expansion \(v=\sum_{T\ne\varnothing}a_Tu_T\): recursively take \(a_T=v(T)-\sum_{U\subsetneq T}a_U\) starting with singletons. For the game \(u_T\), the null-player axiom gives zero to players outside \(T\) and symmetry forces equal shares inside \(T\). Efficiency makes those shares sum to one, so each player in \(T\) gets \(1/|T|\). The additivity and homogeneity axioms then determine every share for \(v\). The permutation formula yields exactly these values: in \(u_T\), the marginal contribution is one precisely when the player is last among the elements of \(T\), an event of probability \(1/|T|\). This proves existence and uniqueness under the axioms.

The last slide shows why efficiency determines the sum of the attributions without identifying the score change when one feature is removed. The displayed word “very” is attributed 19.9 percentage points, while its deletion changes the displayed prediction from 97.8% to 88.7%, a 9.1-point difference. The deletion is one coalition’s marginal contribution, whereas Shapley averages all predecessor coalitions. A smaller example is \(v(\{1,2\})=1\) and \(v(S)=0\) otherwise: each attribution is \(1/2\), even though removing either feature from the full coalition loses the entire unit.

For two features the argument gives

\[\phi_1=\tfrac12(v(\{1\})-v(\varnothing))+\tfrac12(v(\{1,2\})-v(\{2\})).\]

A symmetric interaction visible only when both features are present is divided in half. The definition of \(v(S)\) determines which interaction is being explained: averaging missing features independently and taking a conditional expectation can produce different coalition values.

Challenge

For \(F(x_1,x_2)=x_1^2 x_2\), compare Integrated Gradients and baseline Shapley at \((2,3)\) relative to \((0,0)\). Explain the discrepancy.

Show solution

Along \((2t,3t)\) the partials are \(12t^2\) and \(4t^2\), giving Integrated Gradients \((8,4)\). The baseline game is zero unless both features are present, in which case its value is 12. Each variable is last in one of the two permutations and receives attribution 6. Along the straight path the two factors of \(x_1\) give it twice the attribution of \(x_2\). In the baseline game both features are equally necessary, and arrival order splits the payoff evenly. Both totals are 12.

Second challenge. For \(F(x_1,x_2)=x_1^2x_2\), compare Integrated Gradients from zero with Shapley values from zero masking.

Show solution to the second challenge

On the straight path \(tx\), the first partial derivative is \(2t^2x_1x_2\) and the second is \(t^2x_1^2\). The Integrated Gradients are \((2/3,1/3)F(x)\) after integrating \(t^2\) from zero to one. Under zero masking neither feature alone yields any value and the two-feature coalition yields \(F(x)\), so Shapley gives \((1/2,1/2)F(x)\). Both satisfy completeness, with different allocations of the interaction because one measures increments along a continuous path and the other averages discrete coalition orders.

Research challenge — why KernelSHAP’s regression uses that kernel

Let \(N\) have \(n\ge2\) features, and assume \(v(\varnothing)=0\). Fit an additive model \(g_\phi(S)=\sum_{i\in S}\phi_i\) by minimizing the coalition residuals

\[\sum_{0<|S|<n} w_{|S|}\bigl(g_\phi(S)-v(S)\bigr)^2,\qquad w_s=\frac{n-1}{\binom ns\,s(n-s)},\qquad \sum_{i=1}^n\phi_i=v(N).\]

Prove that the unique minimizer gives the exact Shapley values. Use the unanimity games \(u_T(S)=\mathbf1\{T\subseteq S\}\) and derive why summing over coalition sizes with these weights yields the factor \(1/|T|\).

Show research challenge solution

The quadratic form is positive definite because every singleton is observed with positive weight and its model score is \(\phi_i\). The constraint is feasible, and strict convexity gives a unique minimizer. With the constraint enforced by a Lagrange multiplier, the solution is linear in the vector of game values, including \(v(N)\) on the right of the constraint. It suffices to prove the result for \(u_T\), since those games span all normalized games.

Write \(t=|T|\). The candidate is \(\phi_i=1/t\) on \(T\) and zero outside. It is feasible. At a constrained optimum all coordinates of the objective gradient agree. The candidate and the objective are symmetric separately within \(T\) and its complement, so it remains to compare the gradients of \(i\in T\) and \(j\notin T\) when \(t<n\). Coalitions containing both or neither cancel in that difference. Pair a coalition of size \(s\) containing \(i\) and omitting \(j\) with the coalition obtained by swapping them. The model difference in each pair is \(1/t\). The value difference is one exactly when all \(t-1\) remaining elements of \(T\) lie among the \(s-1\) other members. Its mean over all such pairs is

\[p_{s,t}=\frac{\binom{s-1}{t-1}}{\binom{n-2}{t-1}},\]

where the numerator is zero if \(s<t\). There are \(\binom{n-2}{s-1}\) pairs, and multiplying this number by the regression weight \(w_s\) gives \(1/n\) for each size. Thus the gradient difference divided by two is \((1/n)\sum_{s=1}^{n-1}(1/t-p_{s,t})\). The identity \(\sum_{s=1}^{n-1}\binom{s-1}{t-1}=\binom{n-1}{t}\) follows by grouping \(t\)-subsets of \([n-1]\) by their largest element. Therefore \(\sum_{s=1}^{n-1}p_{s,t}=(n-1)/t\) and the gradient difference is zero. When \(T=N\), every gradient coordinate agrees by symmetry. In both cases the candidate is the unique optimum. These \(\phi_i\) agree with the Shapley values on every \(u_T\), so linearity extends the result.

In practice there are \(2^n-2\) interior coalitions. Sampling them approximates this regression and need not yield the full-coalition minimizer.
