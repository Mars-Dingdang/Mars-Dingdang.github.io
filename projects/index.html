PaperReader

A desktop workspace for bilingual paper reading. It translates PDF or LaTeX sources into Chinese while retaining equations, figures, and tables, then opens the original and translated documents side by side with annotations and passage-grounded chat.

React · TypeScript · Python · LaTeX

ACG Renderer

A course team’s C++ path tracer with a CUDA/OptiX backend. The ferry scene brings together physically based materials, indirect lighting, participating media, and hair scattering. The image shows our 4K OptiX render at 512 samples per pixel.

C++ · CUDA · OptiX · Blender

  • GitHub

LLM Post-Training

A post-training pipeline for Qwen2.5-1.5B covering supervised fine-tuning, GRPO, and evaluation on GSM8K and MMLU. The course project compares a baseline rollout with vLLM and experiments with bounded asynchronous rollout inspired by AReaL.

Python · PyTorch · DeepSpeed · vLLM
